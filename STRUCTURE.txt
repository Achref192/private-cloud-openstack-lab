ENDPOINTS API
=============

GET    /api/tasks           Liste toutes les tâches
POST   /api/tasks           Crée une nouvelle tâche
GET    /api/tasks/:id       Récupère une tâche par ID
PUT    /api/tasks/:id       Met à jour une tâche
DELETE /api/tasks/:id       Supprime une tâche
GET    /api/tasks/stats     Statistiques des tâches
GET    /api/health          Health check de l'API

COMMANDES RAPIDES
=================

Développement local :
  cd backend && npm install && npm run start:dev
  cd frontend && npm install && npm run dev
  cd backend && npm run seed

Build production :
  cd backend && npm ci && npm run build
  cd frontend && npm ci && npm run build

Déploiement OpenStack :
  cd deploy && ./deploy-vm2.sh <VM2_IP> <PASSWORD>
  cd deploy && ./deploy-vm1.sh <VM1_IP> <VM2_PRIVATE_IP> <PASSWORD>

Test avec Docker :
  cd deploy && docker-compose -f example-docker-compose.yml up -d

Logs sur VM :
  sudo journalctl -u cloud-metrics-app -f
  sudo tail -f /var/log/nginx/access.log
